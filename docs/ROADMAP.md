# Roadmap

The roadmap is evidence-driven. Features move only when their authorization and privacy boundaries can be tested.

## 0.1 — Local handoff protocol

- Skills-only Codex plugin
- Markdown and JSON handoff formats
- Workspace snapshot and freshness checks
- Evidence requirements for verified claims
- Secret and PII warnings
- Synthetic examples and automated tests

## 0.2 — Evaluation and adapters

- Public evaluation set for plan-versus-implementation mistakes
- Receiver-action accuracy benchmark
- Codex and Claude Code bootstrap adapters
- Better public-redaction profiles
- Compatibility reports from independent users

## 0.3 — Optional storage

- Design an opt-in handoff store with authentication, encryption, retention, deletion, and audit logs
- Keep raw transcripts out of the service by default
- Publish a protocol compatibility suite before any hosted implementation

## Not committed

- Automatic access to arbitrary chat history
- Automatic task creation or forking
- Default cross-device synchronization
- Background upload of conversations or repositories
- Claims of complete context recovery
